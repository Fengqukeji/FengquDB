# 存储与可靠性

FengquDB 是可嵌入应用进程的数据库。Wiki 系统使用事务将来源正文、索引和编译任务一起保存。

可靠写入在返回前等待持久化。更新资料时，来源修订号发生变化，依赖旧来源的知识页会标为过期并重新编译。

编译任务调用模型时不持有写事务。任务返回后再次核对来源版本，避免旧结果覆盖新知识。

回答中标记的数据库版本来自提取证据的同一快照；取版本不调用需要写锁的完整统计接口。

服务端默认开启后台维护，采用 SDK 默认维护读写预算。当前底座在可选固定读写配额耗尽时可能要求重开数据库，因此接入不设置该可选配额。来源、知识页与索引仍保留事务和查询安全预算。

原始来源按修订保留，正文分段和知识页都供实际检索使用。原文、向量、索引和仍被引用的历史会占用空间；正式整理只回收废弃物理记录，不删除仍有效的资料修订。
