# 页增量编辑优化审查

本批已将 `src/paged/page.hpp` 和 `tests/paged_io_tests.cpp` 两个文件合入主工程。隔离副本、基线清单、原件及合入记录位于 `build/page-lab-20261107/`。这是缓存与首次复制优化之后的独立改动；此前两份 BUFFERED 写队列提案仍保持隔离。

## 改动与稳定性边界

旧页更新即使编码长度及字符串地址不变，仍逐一处理后续偏移、重绑所有键视图，并扫描整页重新计算版本与到期摘要。本批只处理发生变化的部分：长度改变时才移动后续偏移；缓冲地址改变时重绑整页，同地址变长时重绑后缀，等长覆盖时只重绑当前键。插入及单调变化使用增量最大值、最小值；替换旧极值且可能令摘要反向变化时，仍完整扫描。

完整私有二进制缓冲仍直接覆盖和裁剪；分裂依旧复制完整缓冲一次，再从两侧减去不需要的区间。未增加 Page 成员、公共 ABI 或磁盘格式，未修改写队列、检查点的锁范围和后台任务政策。逐次精确 reserve 也未在本批调整。

审查覆盖编码先于缓冲修改、插入前预备可能分配的元数据、键视图引用原缓冲、字符串移动与重分配、插入/替换的后缀偏移，以及最大版本下降、最早 TTL 移除、删除引用和旧分支未知到期摘要的回退。本批审查未发现尚未修复的正确性问题。

新增独立 std::map 模型在叶页、分支页各执行 512 步，包含变长键、别名键视图、插入、覆盖、旧快照及最后分裂；每步重新解码并核对键视图、偏移、字段与摘要。首次辅助测试因 const 指针列表推导失败而未进入运行，修正测试变量 const 后两平台重新构建通过；原错误日志保留。

## 后台回收仍未解决

四项 60 秒样本的后台整理完成次数均为 0。末次状态均为 OK，但它只代表最后一项维护状态，不能据此推断期间没有超时；当前指标没有累计超时次数。活动文件持续增长，短测速度不能代替受控稳态。

代码审查确认，当前 compact 的临时目标属于本次任务；期限或额度使任务退出后释放目标，后续后台周期重新开始。在持续写入下，这种整任务重试可能反复做工，需要继续定位失败阶段并设计可续做的有界维护。Page 优化减少了页操作，尚未改变该调度与恢复协议。检查点仍在写租约内完整 fold_delta，未宣称已消除全部长停顿。
