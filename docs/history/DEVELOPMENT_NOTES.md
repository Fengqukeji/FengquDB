# FengquDB

原生条件表达式、独立排序/Top N、聚合分组、字符串匹配、自动索引选择/Explain 及多源等值关联已加入 C++ 核心，提供 C++、C#、Java、Python 接口和资源预算，见 [复杂查询](../STORE_SELECT.md) 与 [实现、验证和性能](../STORE_SELECT_REVIEW_20261110.md)。

原生 C++17 进程内数据库底座，项目直接链接或加载库，在自己的进程内读写。核心使用分页 `Store`：数据库路径为目录，页和值按需读取，缓存受预算限制。运行时不依赖第三方数据库、Google Protobuf 或 Abseil。

当前源码默认使用**性能模式，50 ms／1 MiB**。普通同步写在事务内存原子生效、可读取后返回；后台按周期或字节阈值可靠同步。关键写传 `force_reliable=true`，或配置可靠模式，等待刷盘后成功。配置持久保存、状态查询与风险边界见 [写入策略](../STORE_WRITE_POLICY.md)。全局ABI已升级为**2**，绑定、头文件和原生库必须配套重编译，历史SDK包不能混用。

当前模式的服务器业务复测见 [性能报告](../STORE_PERFORMANCE_MODE_20261109.md)，代码审查与跨平台验证见 [接入审查](../STORE_WRITE_MODES_REVIEW_20261109.md)。

差分CRC、提交缓存、旧缓存版本退役、事务元数据复用及完成通知优化已接入；整存、转账与50 ms对照见[最新优化报告](../STORE_SAVE_TRANSFER_REVIEW_20261109.md)。当前默认值与剩余短板见[默认参数与空闲验证](../STORE_DEFAULT50_REVIEW_20261109.md)。冷读重复校验的修复、P99含义及事务冲突核对见[冷读与并发说明](../STORE_COLD_READ_REVIEW_20261109.md)。

本项目尚未发布。当前源码只保留 `Store` 引擎及 C/C++、C#、Java、Python 接口，已删除旧单文件 `Database` 引擎、接口和迁移器。`artifacts/` 下旧开发包和历史测量保留供追溯，不代表当前源码。当前移除与性能诊断见 [Store 核心审查](../STORE_CORE_REVIEW_20261108.md)。此前五方案 1280 项扫描、960 项三轮峰值复测见 [历史比较](../DOCKER_FINAL_COMPARISON_20261108.md)。

开发版 Store 的可配置目录、短文件布局和 Unity 接入见 [目录规范](../STORE_LAYOUT.md)，原子/批量接口见 [Store 操作](../STORE_OPERATIONS.md)，复合范围查询见 [Store 查询](../STORE_QUERY.md)，持续增量备份见 [历史保留](../STORE_HISTORY.md)，缓存与检索增量接入见 [变更订阅](../STORE_WATCH.md)。

维护任务可按需限制文件读写请求量，并返回 I/O 统计；后台维护支持整轮共享额度，见 [维护 I/O 预算](../STORE_IO_BUDGET.md)。

热点读取的发布序号复用、直接只读字段投影及准备投影读取器已接入全部语言；空间回收前的首次文件转换分片让出写线程，并在写屏障外预同步镜像，最终发布与恢复屏障保留。接口见 [共享读取](../STORE_SHARED_READ.md) 和 [字段投影](../STORE_QUERY.md)，测量与验证见 [本轮接入记录](../STORE_READ_MAINTENANCE_MERGE_20261110.md)。

普通共享读取已进一步减少引用计数操作，读取器按记录增量刷新，复用无关写入后仍有效的结果。实现审查及最新性能模式的服务器专项与历史数据库比较见 [读取复用与专项复测](../STORE_READ_REUSE_REVIEW_20261110.md)。

写线程已接入自适应短等候：连续交互保持短暂热状态，空闲进入OS等待，单CPU禁止等候预算增长。50 ms／1 MiB保持不变；当前代码的定向性能、空闲开销及整存/批读研究见 [自适应等候报告](../STORE_ADAPTIVE_WAIT_20261110.md)。此前完整服务器矩阵属于本次改动前的历史版本。

公共二进制差异内核和有界多段整存已接入：完整覆盖写统一复用缓存旧值识别少量变化，变化密集、冷值或收益不足时完整写入；已知范围的patch继续直接减法裁剪。实现、恢复边界、Windows/Linux验证及最终整存对照见 [差异内核接入](../STORE_BINARY_DIFF_MERGE_20261110.md)。

普通批读已复用索引位置、减少临时所有权计数，并合并有界预算申请；128 B/8线程读取32份档案的三轮吞吐提升约27.5%，阈值保持不变。实现、边界与验证见 [批读优化](../STORE_BATCH32_REVIEW_20261110.md)。

列表连续读取、范围游标预算复用和条件查询的请求内索引页复用已接入。64项列表三轮中位吞吐提升约129%，4096项范围扫描约10.5%；条件查询的收益及波动、事务与预算边界和跨平台验证见 [列表与查询优化](../STORE_LIST_QUERY_OPTIMIZATION_20261110.md)。

热点多键字段加减可使用 `add_i64_fields`：读取、检查和修改在现有写线程内作为一笔原子命令完成，支持 C/C++、C#、Java、Python。启用后台整理后的默认检查间隔为 200 ms，最小占用与增长触发均为 32 MiB；首次镜像转换使用较大的临时复制块，有限 I/O 预算下保留 4 KiB 推进。调用示例与边界见 [原子字段命令](../STORE_FIELD_COMMANDS.md)，当前代码的验证与定向复测见 [接入记录](../STORE_HOT_MAINTENANCE_MERGE_20261109.md)。

分段文件、可续进度的空间回收及原子操作私有事务额度修复已合入；严格模式保留原提交调度，性能模式采用专用写线程，完整私有二进制缓冲的减法裁剪保留。安装接入、日志轮转与超内存存活数据验证见 [采用记录](../STORE_ADOPTION_REVIEW_20261107.md) 和 [当前验收](../GOAL_ACCEPTANCE_20261107.md)。向量检索、全文检索和 RAG/Wiki 留待以后设计。

可复现的实际磁盘空间/内存故障、外部强杀恢复及默认日志保留压力见 [资源验证](../RESOURCE_VALIDATION.md) 和 [运行记录](../RESOURCE_REVIEW_20261107.md)。
