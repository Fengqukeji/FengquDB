# 数值上限与长期运行

Store 将影响一致性的编号与仅用于观察的累计统计分开处理。事务版本、检查点序号、代际与保存点不能静默回绕；资源预算在增加前检查剩余额度。测试通过构造边界状态跳转到极值，不声称实际执行了 2^64 次操作。

| 数值 | 达到边界时的行为 | 宿主处理 |
| --- | --- | --- |
| 事务版本 uint64 | 最后一个可用版本可提交；随后需要新版本的修改返回 LIMIT。未变化写入、条件不匹配或空事务可能仍返回已有版本 | 读取、校验和备份仍可用；整理及完整备份保留逻辑版本，不会重置它。需要重新开始版本空间时，由业务将逻辑数据导入新的独立库 |
| 每代文件的检查点序号 uint64 | 序号耗尽后，先拒绝新 WAL；需写检查点时，在追加索引页之前拒绝 | 关闭有关旧事务后执行 compact，换到新代际，序号重新开始；事务版本保持不变 |
| 数据代际 uint64 | 最大编号时 compact 返回 LIMIT，不创建回绕后的代际或替换 CURRENT | 原库仍可读写；可完整备份到独立身份的库目录，独立库的代际从 1 开始 |
| 保存点 ID uint64 | 最后一个 ID 可用，之后创建返回 LIMIT；已有保存点仍能回滚/释放 | 保存点只属于该事务。另有最多 1024 个同时保留的保存点限制，应及时释放 |
| 原子整数 int64 | 正负溢出、结果超出业务指定范围时返回 CONSTRAINT，不发布修改 | 业务明确边界或改用更合适的数据表达，不能依靠回绕表示余额等数值 |
| 集合计数 | 有效计数不超过 INT64_MAX；超过的已编码元数据视为 CORRUPT。新增超限由事务失败隔离 | 不要直接修改系统集合元数据。List 另有有界的左右位置编号，空 List 会重置到中间位置 |
| TTL | 0 表示不设置到期；原生到期毫秒使用 uint64，等于截止时间即过期 | Java 的 TTL 时间输入保持非负 long 范围；不要将版本的无符号位模式规则套用到时间与预算 |
| 超时 | 转换为单调时钟期限前检查表示范围，超限返回 INVALID_ARGUMENT | 使用有限且合理的期限；0 表示不限时，不要用 UINT64_MAX 代替 |
| 文件偏移 | 按有符号 64 位文件位置检查 offset 与 length，追加前检查剩余范围 | 文件系统、平台或磁盘空间可能更早拒绝。不能把数值可表示上限解释为承诺支持该体积 |

检查点序号在正常文件中还受文件大小先行约束；极值夹具主要验证边界防御和不可信磁盘状态，不代表正常负载很快就会达到该值。

此前实现只在封存新检查点时检查序号，导致极值状态仍可能接受 WAL，随后无法重开。本次在提交和检查点折叠前增加检查，并在恢复扫描结束后、修改原文件前确认仍有封存序号。对于旧版本已经留下完整或不完整尾部的耗尽文件，重开返回 LIMIT 且保留原字节，不反复追加索引页或先截断再失败；该状态没有新增自动修复工具，须保留源文件进行专项恢复。正常新写入路径会在产生这种状态前拒绝。

## Java 的版本位模式

版本在 C/C++、C#、Python 中分别为 uint64、ulong、任意精度整数。Java 使用 long 保存同一组 64 位，超过 Long.MAX_VALUE 后显示为负数；它仍是有效版本：

```java
long version = db.getEntry(key).version;
String display = Long.toUnsignedString(version);
boolean newer = Long.compareUnsigned(version, previous) > 0;
db.compareExchange(key, version, replacement);
```

CAS、订阅起点/确认、历史水位、增量备份起点和按版本恢复均接受返回的完整位模式。FQDB_HISTORY_CURRENT 的全 1 位模式在 Java 为 -1，用于选择当前版本；版本输入由原生层按无符号历史边界校验。时间、大小、数量及超时仍有各自的非负输入契约。

累计命中、I/O、合组及后台计数用于诊断，不是事务版本或恢复依据；它们为 64 位观测计数，不能当作永不回绕的业务序列。高频路径未为每次统计增加饱和分支。维护 I/O 额度则在请求前检查加法和预算边界，不能用诊断统计代替额度控制。

原生验证入口为 CTest `paged_limits`；生产库的多语言边界由 `scripts/verify-store-numeric.py` 驱动。它使用不进入运行库的夹具生成器构造合法边界文件，再通过正式 Java/C#/Python 绑定操作。实际证据和构建差异见 [数值边界审查](STORE_NUMERIC_REVIEW_20261107.md)。
