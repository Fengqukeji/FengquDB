# 原调度私有事务额度修复审查

本轮将私有事务生命周期修复从 buffered 自然合组提案中拆出，保留原调度。在未修改的原内核上实际复现了低快照额度错误，修复候选通过两平台原生、消毒器、竞态、三语言并发与独立重开验证。性能仍有正负变化，候选尚未合入主工程，不能称为全部负载提速。

证据目录为 `build/atomic-owner-lab-20261107/`。从原 SDK 的 137 文件清单派生两个 138 文件副本，两者加入完全相同的测试及 CMake 接线；候选只比对照多改 `core.hpp`、`group.hpp`、`operations.hpp`。BUFFERED 继续调用线程直接提交，SYNC 继续原有提交队列；没有使用 v2 的自然合组、排队撤出或写句柄提案。完整私有二进制缓冲和 0.3.1 减法裁剪保持不变。

## 原版缺陷与修复

保留六个普通 Capture，将快照上限设为八，再把八个原子累加请求排到持有的 WriterGate 后面。原版逐笔准备出的私有事务在整组完成前不释放，因此两笔成功、六笔返回 FQDB_LIMIT，发布前占满八个槽位，最终计数及版本只有二。

Windows 与 Linux ASan/UBSan 的原版不变量检查均实际退出 1，原始输出保留在 `windows-baseline-invariant.log` 和 `atomic-baseline-invariant.log`。随后复现模式检查两种文件布局均为上述 2/6 结果，并核对成功前缀及重开数据。这些是原版缺陷证据，不能写成原版功能测试通过。

候选把 AtomicUpdate 的私有事务改为 optional 原位构造，减少一次堆分配。waiter 安装一次性的 noexcept 清理回调，在 append 完成或抛出后立即释放私有对象；此时 WAL 不再借用暂存数据。回调先清空自身，后续完成函数检查空指针，覆盖无变化、准备失败、写入/同步失败以及中止整个组的路径。外部普通事务不安装回调，仍保留原有持有关系、冲突重试和取消状态。

修复后的同一回归完成全部八次累加，值及版本连续为 1..8，发布前只占六个普通快照槽。另以单槽额度覆盖成功、比较不匹配、无变化、准备失败、Capture 创建失败、部分 WAL 写入失败、刷盘失败、写者中毒及恢复后继续写入；检查归还快照/事务额度、旧快照隔离和普通事务失败后仍持有写集。

初次准备副本时，目录复制带入了原 SDK 目录中不属于源码清单的旧 C#/Python 构建产物，138 文件断言实际发现 208 个文件，尚未开始构建。`failed-prepare.json` 和 `unfiltered-baseline/`、`unfiltered-source/` 保留失败现场；改为只复制清单路径后，两个正式输入各为 138 文件。没有删除或修改原 SDK 的构建产物。

三语言回归直接使用当前源码的适配器：Java 和 C# 在原生计时结束后编译，Python 从受测源码加载；Java 复用未改动的 SDK JNI 二进制，通过稳定 C ABI 加载新核心，两个平台均启用 `-Xcheck:jni`。Linux C# 使用真实 Linux .NET host 执行。没有把旧核心的绑定记录当作本轮结果。

每个组合保留六个普通快照，上限八，用八个线程完成首轮八笔及后续 256 笔累加，检查值和版本完整覆盖 1..264、无变化操作不增版本、约束失败后仍可调用、旧快照仍未看到计数器，随后关闭重开。另起同语言进程只读核对值/版本和验证数据库，避免只检查同一进程中的状态。测试源码及构建、JNI/核心哈希位于 `bindings/` 和两平台绑定报告。

本批没有重新模拟真实 ENOSPC、地址空间分配失败或 cgroup OOM，也没有完成新格式长期稳态回收；故障注入回归不能代替这些实际资源条件。

## 后续验收

独立修复已具备上述原生及语言证据，仍保持隔离。下一步以本候选继续新格式真实磁盘/内存异常与受控长期回收验收，并保留吞吐和尾延迟变化，避免将微小短时波动直接变成下一轮实现依据。自然合组的剩余成本另外诊断，不与本次资源修复混在一起。完整五方案最终比较、最终包体和采用审查尚未完成，长期目标保持进行中。

向量检索、全文检索、RAG/Wiki 留待以后设计；不增加跨进程协作、远程服务、权限或复制。

后续已对同一核心二进制补做两布局 22 次真实资源故障/恢复，并完成两种持久性各 48 轮回收、独立重开与继续写入。最大逻辑尾部超过 4 GiB，保留旧快照、patch 模型和默认 64 MiB 物理段均通过；探针自身的编译和等待条件错误保留并修正，核心未改。新证据与有限验证边界见 [实际资源与受控回收审查](STORE_ATOMIC_RESOURCE_REVIEW_20261107.md)。
